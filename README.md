INSTRUCTIONS FOR RUNNING THE APPLICATION
Both source files (Product.java and Main.java) are in the package "coursework".
   The entry point is the main method in Main.java.
Using Eclipse:
1. Import the project into Eclipse.
2. Right-click Main.java, then choose Run As > Java Application.
3. The output is displayed in the Console.
   The program needs no user input. It creates the products, displays the
inventory, updates a price and a stock quantity, displays the inventory
again, and then tests an invalid (negative) price.
